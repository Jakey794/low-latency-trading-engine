Low-Latency Event-Driven Trading Engine

Portfolio dashboard — correctness-first simulated trading stack

Disclosure: This is an educational portfolio project. Not investment advice. No profitability claims. No exchange-grade latency claims. Benchmark numbers are machine-specific — regenerate on your hardware.

Architecture

Event-driven pipeline: JSONL replay → Runtime (router, risk, portfolio, strategies) → per-symbol matching engines → ordered outputs.

  • Full architecture doc
  • Mermaid source
  • Crates: engine, engine-cli

Feature highlights

  • Limit order book with price-time priority
  • Deterministic JSONL replay + golden tests
  • Portfolio P&L (average cost, i128)
  • Pre-trade risk + kill switch
  • Market-making & momentum demo strategies
  • Multi-symbol replay
  • Criterion benchmarks, Python baseline, proptest
  • Elite experiments: order pool, lock-free queue (feature-gated)

Quick commands

Verify 
./scripts/verify_final.sh
Demo 
./scripts/demo.sh
Replay 
cargo run --release --bin engine-cli -- \
  replay data/scenarios/basic_cross.jsonl
Strategy 
cargo run --release --bin engine-cli -- \
  strategy-replay ... --strategy market_making

Limitations

  • No live exchange connectivity or real capital
  • No persistence or production deployment model
  • Batch replay (full input in memory)
  • Demonstration strategies only
  • Benchmarks are environment-specific microbenchmarks
