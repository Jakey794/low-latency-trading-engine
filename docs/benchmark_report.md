## How to regenerate

1. **Compile benches:**
   ```bash
   cargo bench --workspace --no-run
   ```

2. **Run full Criterion suite:**
   ```bash
   BENCH_FULL=1 cargo bench -p engine --bench engine_hot_path
   ```

3. **Run Python baseline:**
   ```bash
   python3 python/baseline_lob.py --events 10000
   ```

4. **Optional — populate `out/bench_summary.json`:**
   Manually merge Criterion output and Python JSON into the schema expected by `scripts/generate_charts.py`:
   ```json
   {
     "workloads": [
       {
         "workload": "10000_events",
         "latency": { "p50_ns": 0, "p90_ns": 0, "p95_ns": 0, "p99_ns": 0, "max_ns": 0 },
         "throughput": { "events_per_sec": 0 }
       }
     ],
     "comparisons": {
       "rust_engine": { "label": "Rust engine", "events_per_sec": 0 },
       "python_baseline": { "label": "naive baseline", "events_per_sec": 0 }
     }
   }
   ```

5. **Generate charts:**
   ```bash
   python3 scripts/generate_charts.py
   ```

6. **Update this document** with measured values and environment table.

## Interpretation guidelines

- Report median and tail latencies separately; a low p50 with high p99 indicates jitter.
- Compare release builds only (`cargo bench` uses release by default for benches).
- Do not extrapolate local microbenchmarks to co-located exchange latency.
- State sample size and Criterion configuration (see `engine_hot_path.rs`).
