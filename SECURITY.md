# Security Policy

## Supported versions

Security fixes are considered for the latest commit on the `main` branch.
This is an educational portfolio project and does not provide a production
service, live trading, or security support SLA.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in a public issue. Use
GitHub's **Report a vulnerability** control in this repository's Security tab
to create a private report. Include a minimal reproduction, affected commit or
component, impact assessment, and any suggested remediation.

The maintainer will acknowledge reports as time permits, investigate them
privately, and coordinate a fix before public disclosure where appropriate.

## Scope

The project accepts reports for repository code, build and CI configuration,
and documented local-only demonstrations. Third-party dependencies should also
be reported upstream when appropriate.
